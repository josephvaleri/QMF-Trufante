# Question My Faith - Application Summary

## 🎯 **Project Overview**
Question My Faith is a Next.js 16 application that provides an AI-powered chat interface for faith-based conversations. The application allows users to ask questions about faith, spirituality, and religious topics, with responses generated by OpenAI's GPT-4o model enhanced with a custom knowledge base.

## 🏗️ **Technical Architecture**

### **Framework & Dependencies**
- **Next.js 16.0.0** with App Router
- **React 19.2.0** with TypeScript
- **Tailwind CSS 4** for styling
- **OpenAI API** for AI responses
- **Vector Store** for document retrieval

## 🔄 **Data Flow**

1. **User Input**: User types question on home page
2. **Navigation**: Redirects to `/chat?q=question`
3. **Chat Display**: Question appears in chat interface
4. **API Call**: Client calls `/api/ask` with question and history
5. **OpenAI Processing**: Server calls OpenAI API with streaming
6. **Response Streaming**: Real-time response chunks sent to client
7. **UI Update**: Response appears progressively in chat
